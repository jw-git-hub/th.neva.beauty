# th.neva.beauty

Сайт салона красоты **Neva Beauty — Koh Samui** (о. Самуи, Таиланд): 25 статических
страниц, которые собирает генератор на Python + Jinja2 и публикует GitHub Pages.

Сайт пересобран со старой выгрузки Tilda (`doctor-cosmetolog.pro`, бренд
«Avocado Beauty») на генератор соседнего салона сети — `vn.neva.beauty`.

---

## Как это устроено

Всё содержимое сайта лежит в четырёх файлах данных. HTML собирается из них по
шаблонам и целиком попадает в папку публикации — база данных и код на сервере
не нужны, GitHub Pages отдаёт готовые файлы.

```
generator/data/*  →  generator/build.py + templates/*  →  th.neva.beauty/
   данные                    сборка                       то, что скачивает браузер
```

**Правило:** в `th.neva.beauty/` лежит только то, что скачивает браузер.
Всё, из чего это собрано, — в `generator/sources/`. CSS-слои, SVG-иконки,
мастер-кадры и мастера шрифтов в деплой не попадают: страницы ссылаются
на склеенный `bundle.min.css` и на нарезанные `.webp`, исходники по ссылке
никто не запрашивает.

### Что где лежит

| Путь | Что это |
|---|---|
| `generator/data/site.yml` | Бренд, контакты, адрес, часы, Метрика, данные для schema.org |
| `generator/data/content.yml` | Тексты всех страниц: главная, 6 разделов, 17 услуг, FAQ |
| `generator/data/prices.json` | Прайс — источник истины по ценам, 204 позиции |
| `generator/data/lastmod.json` | Журнал отпечатков страниц для честного `lastmod` в sitemap |
| `generator/templates/` | Jinja2-шаблоны страниц и `partials/` — шапка, футер, FAQ, дровер |
| `generator/sources/css/` | Девять CSS-слоёв, из которых склеивается бандл |
| `generator/sources/icons/` | 20 SVG-иконок, встраиваются в HTML на сборке |
| `generator/sources/img/` | Мастер-кадры и `CREDITS.txt` — происхождение каждого кадра |
| `generator/sources/fonts/` | Вариативные мастера Cormorant и Manrope + лицензии OFL |
| `th.neva.beauty/` | Результат сборки — то, что уезжает на GitHub Pages |
| `docs/superpowers/` | Спека проекта и план сборки |
| `docs/audits/` | Отчёты аудитов этапов 5, 7 и 8 |
| `TODO.md` | Сквозной чек-лист работ по проекту |

### Модули генератора

- **`build.py`** — сборка. Читает данные, склеивает и минифицирует CSS-бандл,
  рендерит страницы, собирает `sitemap.xml`, `llms.txt` и `CNAME`.
- **`schema.py`** — JSON-LD: общий граф бизнеса (Organization + WebSite) плюс
  узлы страницы (Service, OfferCatalog, FAQPage, BreadcrumbList, ItemList).
- **`images.py`** — таблица ширин и `sizes` для адаптивных картинок. Один
  источник правды: по ней и режутся файлы, и подставляется `srcset`.
- **`check_prices.py`** — парити-тест цен: сверяет `prices.json` с ценами
  в собранном HTML. Требование к сайту — 100% точность цен.
- **`check_content.py`** — проверки качества: следы старого бренда, битые
  внутренние ссылки, отсутствующие картинки, дубли метатегов, невалидный JSON-LD,
  знаки, которых нет в подрезанных шрифтах.
- **`make_images.py`**, **`make_fonts.py`** — ручные утилиты пересборки
  исходников. На сборке страниц не запускаются, результат коммитится.

### Приёмы, о которых стоит знать заранее

- **Цены в текстах не пишут цифрами.** В `content.yml` ставят плейсхолдер
  `{price:слаг-услуги:Точное название позиции}` — цену подставит сборка из
  `prices.json`, и текст не сможет разойтись с прайсом. Если название позиции
  у услуги неуникально, его уточняют секцией или подписью после `|`:
  `{price:biozavivka-volos:Длинные волосы со стрижкой|До поясницы}`.
- **Позиции, которые отдельно не продаются, помечают `"addon": true`** —
  надбавка, расходник, цена за единицу препарата. Без флага страница заявит
  в разметке цену, по которой купить нельзя.
- **Раздел становится страницей сам**, если в нём больше одной услуги.
  Раздел из одной услуги страницы не получает — пункт меню ведёт прямо на неё.
- **Ссылки на ассеты несут отпечаток содержимого** (`?v=1a2b3c4d`), поэтому
  после деплоя вернувшийся посетитель не получает из кэша старый CSS.
- **`lastmod` в sitemap меняется, только если страница правда изменилась**:
  отпечаток HTML сравнивается с журналом `lastmod.json`, отпечатки ассетов
  из сравнения исключены.

## Запуск

Нужен Python 3.12.

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
```

Сборка сайта в `th.neva.beauty/`:

```bash
.venv/bin/python generator/build.py
```

Посмотреть результат локально:

```bash
.venv/bin/python -m http.server -d th.neva.beauty 8000
# http://localhost:8000
```

### Проверки

Те же три шага, что и в CI. Любой из них падает — деплой не уезжает.

```bash
.venv/bin/python generator/check_content.py            # 25 страниц
(cd generator && ../.venv/bin/python check_prices.py)  # 204 позиции прайса
.venv/bin/python -m pytest generator/tests -q          # 85 тестов
```

`check_prices.py` запускают из папки `generator` — он импортирует `build`.

### Пересборка исходников

Запускают руками и только когда меняется набор картинок или начертаний;
результат коммитят.

```bash
.venv/bin/python generator/make_images.py   # нарезка .webp по лестнице ширин
.venv/bin/python generator/make_fonts.py    # инстансы и подрезка .woff2
```

## Как внести изменения

**Поменять цену.** Правят `generator/data/prices.json`, пересобирают, гоняют
`check_prices.py`. Тексты с плейсхолдерами `{price:…}` подтянут новую цену сами.

**Поправить текст страницы.** Правят `generator/data/content.yml` — там же
лежат `seo_title`, `seo_desc`, FAQ и блоки преимуществ.

**Добавить услугу.**
1. Раздел в `prices.json` со слагом услуги.
2. Блок услуги в `content.yml` → `services` с текстами, `hero_image` и `benefits`.
3. Слаг в список `services` нужного раздела в `content.yml` → `categories`.
4. Мастер-кадр в `generator/sources/img/<hero_image>.jpg`, строку о нём
   в `CREDITS.txt`, затем `make_images.py`.
5. Сборка и все три проверки.

Меню, хлебные крошки, блок «Смотрите также», sitemap и `llms.txt` соберутся сами.

**Поменять контакты, адрес или бренд.** `generator/data/site.yml` — оттуда
их берут и страницы, и разметка schema.org.

## Деплой

`.github/workflows/` — push в `main` запускает сборку, три проверки и деплой
на GitHub Pages. Домен `th.neva.beauty` прописан в `CNAME`, который генератор
кладёт в артефакт на каждой сборке: иначе workflow сбрасывал бы кастомный домен
в настройках Pages.

Превью по подпути (`user.github.io/th.neva.beauty/`) включают полем `base_path`
в `site.yml` — на SEO-адреса из `base_url` оно не влияет.
